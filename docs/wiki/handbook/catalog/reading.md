## Overview (1)

- [QindaQt project wiki](../../index.md) — QindaQt is a modular, Wayland-first Qt desktop environment. Its distinguishing feature is a hybrid window model: ordinary windows remain independently usable, but users may combine them into a movable container containing tabs and recursive splits.
