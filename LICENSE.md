# QindaQt licensing

QindaQt is free and open-source software.

- Standalone QindaQt applications and the shell use `GPL-3.0-or-later`.
- Reusable QindaQt libraries and SDK interfaces use `LGPL-3.0-or-later`.
- Files derived from KWin or another upstream project retain a compatible
  upstream license and attribution.
- Third-party components remain under their respective licenses.

Every source file must carry an SPDX identifier. The authoritative license
texts are the SPDX-published texts for
[GPL-3.0-or-later](https://spdx.org/licenses/GPL-3.0-or-later.html) and
[LGPL-3.0-or-later](https://spdx.org/licenses/LGPL-3.0-or-later.html).
