# Synthetic password fixture

`password.pdf` is a self-authored, one-page PDF containing only a red rectangle.
It uses PDF Standard Security revision 2 for the renderer/password-flow test;
the user password is `viewer-test` and the owner password is `fixture-owner`.
It contains no private document content. Its license is GPL-3.0-or-later, as
marked in the PDF header. Production encryption is entirely handled by Poppler.

Check independently with `pdfinfo -upw viewer-test password.pdf`; an incorrect
password must fail. The other PDF and image fixtures are generated by the
focused tests using `QPdfWriter` and Qt image writers.

`latin1-password.pdf` is the independent reviewer's synthetic revision-2 fixture
for a non-ASCII password, `café` (Latin-1 bytes `63 61 66 e9`). It contains the
same simple red rectangle and uses owner password `fixture-owner`; its header
declares GPL-3.0-or-later. The controller regression first renders it directly
using Poppler's documented Latin-1 byte API, then unlocks through the QString
facade so an accidental UTF-8 conversion cannot pass unnoticed.
