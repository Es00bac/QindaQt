# Wallpaper runtime finding

The production shell had no background surface at all: only panel and notification layer-shell roles existed. The descendant candidate therefore adds a separate controller that owns one noninteractive Background-layer window per live `QScreen`, consumes the existing confirmed Settings1 scope, resolves bundled `qindaqt:<name>` identities under generic-data roots, and applies scaled/centered/tiled rendering. ADR-0078 records this boundary and supersedes only ADR-0074's wallpaper-application deferral.
