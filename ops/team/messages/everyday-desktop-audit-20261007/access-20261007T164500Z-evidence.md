## Six bounded gaps and acceptance proposals

1. Extend existing QindaTK providers to one additional high-value app at a time. Graphical: grant Read/Edit, inspect visibly bounded state, edit and native Undo. CLI/agent: discover typed actions, refuse stale revision/modal state, deduplicate same request, revoke immediately. Use stable domain IDs, not generic widget scraping; save/export/send need distinct consent.
2. Add scoped desktop session/window context by composing existing authenticated task/window/menu boundaries with QindaTK document discovery. Graphical: choose app/window scope and preview shared metadata. CLI/agent: correlate lifetime IDs, focus generation and revisions; unknown/stale/closed/locked subjects withdraw. No arbitrary agent authority is inherited from Voice1 or panel credentials.
3. Provide one visible access/revoke workflow across granted document scopes and optional capture/input. Graphical: visible active scopes, Stop/Disconnect and understandable read/edit/capture distinctions. CLI/agent: refusal after revoke, owner/process replacement or lock; session opt-in never persists or upgrades via RPC. Preserve existing per-document menus/flags as valid paths.
4. Define privacy/redaction before richer desktop context. Graphical: show excluded fields and allow metadata-only context without pixels. CLI/agent: explicit omitted/redacted markers, bounded results/events and gap recovery; never silently export passwords, credentials, clipboard payloads, voice transcripts or terminal scrollback. Capture has its own consent and cannot recall already-copied pixels.
5. Keep terminal first-class with explicit terminal-specific scopes. Graphical: launch/profile/search/group use remains usable without terminal commands; any agent read selection/transcript choice is explicit and visible. CLI/agent: preserve argv/PTY lifecycle and job-close policy; verify delivery with a private terminal sink, not helper acknowledgement. No automatic execution of terminal text and no retrospective transcript access.
6. Qualify representative end-to-end journeys, including keyboard/AT-SPI and voice. Graphical: launch/find app, edit/save, arrange windows, grant/revoke agent scope, recover refusal and undo without mandatory terminal. CLI/agent: same authoritative state/action result and no hidden replay. Test normal and actual fractional scale, human edits racing actions, app close/owner replacement, lock, omitted state, no provider and unsupported apps. Document human screen-reader and physical-session coverage independently from fixture results.
