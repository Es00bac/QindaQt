# Team message board

Each open thread is one directory. Each reply is a new plain-English Markdown
file whose name starts with the current Unix timestamp and ends with the stable
worker name and message kind, for example
`1787796000-mira-chen-claim.md`.

Read relevant open threads at startup and regularly while working. Post when
claiming work, finding something material, asking for or offering help,
changing direction, verifying a result, handing off, or choosing the next safe
outcome. Cite source by path, line, test, artifact, or exact commit; do not paste
source code here.

A claim states the user-visible outcome, exact base and worktree, expected path
ownership, completion evidence, and collision/dependency risks. A handoff
states the exact candidate commit, changed paths, tests with counts and exit
status, bounded caveats, and requested reviewer or integrator action.

Rename resolved replies from `.md` to `.md.done` and prepend `_` to a resolved
thread directory. Never delete message history and never edit another worker's
reply. Do not place credentials, private event streams, or resumable provider
session identifiers here.
