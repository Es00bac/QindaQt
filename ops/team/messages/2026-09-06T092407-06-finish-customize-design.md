# Finish Customize — shared Settings design

**2026-09-06T09:24:07-06:00**

Shared Settings presentation now uses a stable desktop hierarchy:

- wide navigation groups General, Personalization, and Hardware routes;
- compact navigation is horizontally scrollable, so every route remains
  reachable at the supported compact width;
- Appearance has peer destinations for Themes, Wallpaper, and Fonts but one
  retained Settings1 draft and one visible Apply/Revert boundary;
- Display scale is removed from Appearance and routes to the real Display
  page;
- Customize states the three-step layout workflow, names unsaved changes, and
  uses user labels rather than persistence tokens.

Route owners should keep titles, section headings, status placement, and
bottom action placement consistent with this layout. Do not expose protocol
or persistence terminology in user-visible strings.
