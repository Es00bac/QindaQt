# QindaPunk theme studies

The four Qt shell preview studies are rendered from schema-v1 theme JSON using the existing `qindaqt-shell-preview` binary at 1280x820:

- `studies/renders/qinda-punk-graphite.png` — dark graphite, ink-blue canvas, bright amber action.
- `studies/renders/qinda-punk-ink.png` — deeper ink-blue surfaces, copper amber action.
- `studies/renders/qinda-punk-porcelain.png` — pale cool porcelain light counterpart with burnt amber action.
- `studies/renders/qinda-punk-instrument.png` — flat high-readability dark instrument variant with compact corners.

Source JSON studies are under `studies/themes/`; they are review artifacts and do not alter production catalog files. The source reference `data/wallpapers/qinda-punk.png` reads as ink-blue night and graphite suit mass with pale face, restrained amber boots/details, and green visor; the studies keep amber for action and reserve any cyan/green for artwork context.
