# Startup tutorial fact audit

Verified current user-facing facts from `docs/wiki/architecture/window-containers.md`, `docs/wiki/architecture/hybrid-topology.md`, `docs/wiki/apps/customize-settings.md`, and source:

- Pointer docking: hold Meta+Shift and left-drag (`Meta+Shift+Left`) past the 8-logical-pixel threshold. Edge target creates a split; center/tab-strip target creates a page/tab; dropping outside every valid target detaches a grouped member. An independent window dropped outside cancels. This is a pointer gesture, distinct from the keyboard `Meta+Shift+D` dock command.
- Ordinary movement: plain title-bar dragging moves a floating window. Dragging a grouped member's preserved native title bar without modifiers atomically detaches it and lets KWin continue the ordinary move. Outer-title movement moves the complete container.
- Tabs/pages: top-level tabs select pages. Tabs can reorder, move between containers, detach as a leaf/window or split/new container, and regroup with an independent tab target; edge tab drops are currently rejected. Keyboard page actions include `Meta+Ctrl+PageDown/PageUp` to activate next/previous page and `Meta+Ctrl+Shift+PageDown/PageUp` to reorder; interactive grabs commit with Enter and cancel with Escape.
- Window menu: right-click outer title emits the group context menu (layer, workspace, activity, pin, output); member-title right-click remains native. Global application menus are active-app exports and withdraw safely when unavailable.
- Customize: `qindaqt-settings --page customize` is an available route. Palette/chip dragging commits one Undo step; Escape/cancel/outside release rolls back. Selected applet keyboard controls are Space (move mode), Ctrl+Left/Right (within panel), Alt+Left/Right (zone), Ctrl+Shift+Left/Right (panel), Delete, Ctrl+D, Ctrl+Return apply, Ctrl+Shift+Return discard, Ctrl/Cmd Undo/Redo. Settings Center route shortcuts confirmed in `src/apps/settings_center/Main.qml`: Ctrl+4 Network, Ctrl+6 Audio, Ctrl+7 Bluetooth, Ctrl+8 Power, Ctrl+9 Clipboard, Ctrl+0 Color; Customize has no dedicated Ctrl-number shortcut in current source (navigation can select route).
- No current tutorial/onboarding/show-next-launch implementation exists in `src`/`docs`; a new first-launch tutorial must treat that as new behavior and add persistence/tests. Avoid claiming a current checkbox or tutorial until implemented.
