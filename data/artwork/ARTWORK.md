# QindaQt material artwork

`empty-folder.png` is original generated artwork for the File Manager empty
folder state. It is a 1254 × 1254 RGBA PNG, displayed at a small logical size;
it contains no interface text. The original alpha is preserved.

Generated on 2026-09-08 using the available OpenAI image generation tool. Exact
model identity was not exposed by the tool. Prompt:

> Create an original small desktop empty-folder illustration for QindaQt
> ('kinda cute'). Single isolated translucent smoked-plum glass folder with a
> thick rounded pearl ceramic rim, one tiny apricot tab, softly folded paper
> inside, and an inquisitive tiny rounded rubber duck peeking over the edge.
> Sophisticated tactile product illustration with playful personality, not
> clip art. Pearl, aubergine smoke, muted apricot; no blue, no neon, no text,
> no letters, no UI mockup. Soft studio lighting, very restrained refraction,
> clear compact silhouette readable at 120px. Transparent background with
> preserved alpha. Square composition, generous transparent margins.
> Intended as subtle empty-folder state art for a Linux file browser.
> Generate a PNG asset.

The illustration supplies the material study for this release. Production
command and MIME icons remain deterministic SVG catalog assets. See the
[visual identity](../../docs/wiki/shell/visual-identity.md).
